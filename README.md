“ScriptUI Panels”文件夹中的脚本设计有用户界面，这些界面显示在可停靠面板中；这意味着它们可以放置在任何工作区，并且每次启动应用程序时都会自动打开。您可以在应用程序“窗口”（Window）菜单的底部找到这些脚本。

如果现有脚本使用调板（palette）或窗口作为其主用户界面，则需要对其进行调整，以便在可停靠面板中使用（详情请参阅 After Effects 脚本编写文档）。使用对话框的脚本则不太容易进行此类调整。

您可以将自己的脚本添加到“ScriptUI Panels”文件夹中。



一般的脚本路径 在比如：D:\Software\Program Files\Adobe\Adobe After Effects 2024\Support Files\Scripts\ScriptUI Panels
